# OtakuSekai downloads

Play any time in your browser at **https://play.otakuswonderland.com**, or install the app:

**https://play.otakuswonderland.com/download** (or open the newest entry under *Releases* on this page).

- Windows: run `OtakuSekai Setup ... .exe` (or the no-install `OtakuSekai ... .exe`). Windows may show a blue box the first time: **More info > Run anyway**.
- Mac: open the `.dmg`, drag the app to Applications, then right-click it > **Open** the first time.
- Linux: `chmod +x OtakuSekai-*.AppImage` and run it.

The app is a small launcher that opens the live game, so the game always updates itself: you never need to download an update for new cards or features.

This repository holds only the launcher's source (about 200 lines) and the build recipe. The game itself and its data are not here.
